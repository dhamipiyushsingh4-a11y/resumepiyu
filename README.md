# Manas College — Professional Resume Studio (Enhanced)

A browser-based resume builder branded for Manas College of Science Technology & Management. It runs offline in a modern browser.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Add your profile details, select a design and preview the resume.
4. Use Print / Save PDF or Download HTML to export.

## What's new in this edition
- **32 resume designs** with varied visual systems: two-column consulting, career timeline, modular portfolio grid, signature editorial, profile-first sidebar, venture/startup cards, legal/formal brief, product designer portfolio, and more.
- **Repeatable detailed entries:** add as many work experience records, education records, projects/certifications, and achievements/leadership entries as needed. Each record has its own structured fields and a remove control.
- Rich entry details include role/title, organisation, dates, location, tools, grade/CGPA, responsibilities, measurable outcomes and academic highlights.
- Existing freeform fields remain available for extra details and legacy profile backups.
- Optional profile photo upload with live preview, remove control, JPG/PNG/WebP validation and 5 MB limit.
- Live resume preview, ATS keyword overlap estimate, browser-local auto-save, JSON backup/restore, sample profile, HTML export and print-to-PDF.
- Responsive interface for desktop and mobile.

## Privacy and ATS notes
- Information is processed locally in the browser; no server or API key is required.
- Auto-save uses local browser storage. Export a JSON backup before clearing browser data or changing devices.
- ATS analysis is a keyword-overlap estimate, not a real employer ATS test or a guarantee of selection.
- Only include accurate skills, qualifications, dates and achievements. A photo is optional; use it only when appropriate for the role and application market.
